# Мой проект на Windows Forms

В этом репозитории хранятся исходные коды приложения биржи игровых ценностей.

## 📂 Структура проекта
* **[WindowsFormsApp1](./WindowsFormsApp1)** — Актуальная версия программы с базой данных.

## 🚀 Описание версий

### 🔹 Версия 2
* **Разделение прав доступа:** Реализована система ролей (Администратор, Продавец, Покупатель). Для каждой роли динамически настраивается видимость вкладок и кнопок управления.
* **Безопасная сделка (Escrow):** Интегрирован цикл покупки товара покупателем с автоматическим созданием записей в таблицах `Оплата`, `Сделки` и `Замораживание средств`.
* **Система споров:** Добавлена возможность открытия спора по купленному товару с автоматическим перенаправлением в арбитраж к администратору.
* **Оптимизация:** Исправлены критические ошибки защищенной памяти драйвера С# и MS Access, настроено умное автообновление таблиц при переключении вкладок.
